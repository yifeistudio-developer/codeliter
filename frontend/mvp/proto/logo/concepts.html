CodeLiter — 标志方案

Editorial code & literature. 六个标记方向，统一 32×32 网格、2.4–3px 笔画、墨黑 + 单一粉色强调。每格左侧浅色、右侧深色。

A · 引文括号Code + Text
32 / 16 px

代码块括号包住一行文字：技术承载书写。瑞士式直角，最贴近站点现有的方括号语言。

A2 · 光标括号Cursor
32 / 16 px

括号内是一枚粉色光标，暗示正在书写的下一行。小尺寸下细节偏多，需要 24px 以上使用。

B · 终端手记Prompt + Page
32 / 16 px

折角页面 + 提示符：与站点的「笔记 / 现场记录」叙事一致，但更接近通用文件图标。

C · 书引号‹ · ›
32 / 16 px

尖括号即书名号：代码符号与编辑引号同形。对称、易识别，但略偏通用「代码」图标。

D · 版权页 C.Monogram
32 / 16 px

C 加句点，像杂志版权页的署名标记。最克制、最有出版气质，粉色方块是唯一的节奏点。

D2 · C 与光标Cl ligature
32 / 16 px

C 与粉色竖线组成 Cl 缩写，竖线同时是文本光标。品牌名首尾字母都出现了，但读起来像播放条。

E · 基线句点Baseline
32 / 16 px

句点落到基线下缘，C 的开口变成一句完整的话。重心偏下，与上一种相比更稳定。

F · 双行引文Blockquote
32 / 16 px

两行引文，末行收短并转为粉色，像未写完的句子。语义最完整，但 16px 时偏密。
