# CodeLiter 门户设计交付

## 产品方向

面向技术学习者与开发者的个人技术实践门户，由作者弘毅（Hongyi）维护。首期帮助访客了解作者、发现学习笔记、浏览项目实践，并通过稳定链接分享内容；论坛与管理端暂不进入 MVP。

## 信息架构

| 页面 | 页面任务 | 核心内容 |
| --- | --- | --- |
| 首页 `/` | 快速理解站点并找到入口 | 个人定位、精选笔记、近期项目、关于作者 |
| 学习笔记 `/notes` | 发现并筛选知识内容 | 分类、关键词、分页、阅读时间 |
| 笔记详情 `/notes/:slug` | 专注阅读并定位章节 | 摘要、标签、目录、正文、代码示例 |
| 项目实践 `/projects` | 浏览可验证的实践成果 | 分类、项目状态、技术栈与摘要 |
| 项目详情 `/projects/:slug` | 了解项目的问题与取舍 | 项目背景、技术栈、实践要点 |
| 关于 `/about` | 了解作者与联系途径 | 简介、关注领域、联系方式 |

## 视觉系统

完整色彩、字体、间距、组件与交互规范见 [`design-system/codeliter/MASTER.md`](./design-system/codeliter/MASTER.md)。

- **风格：** 瑞士现代主义与编辑式内容排版；用清晰网格和留白突出文字，不用装饰性图库填充页面。
- **配色：** 近黑色正文、暖白背景与克制的玫瑰粉强调色；状态信息同时使用文字与标记，不只依赖颜色。次要文字在明暗两套主题下均保持 4.5:1 以上对比度。
- **主题：** 支持明亮、暗色与跟随系统；首次访问默认跟随系统偏好，手动选择会被记住。
- **语言：** 支持简体中文与英文；切换后同步更新界面文案、内容示例、筛选项和页面标题。
- **字体：** Public Sans 为界面与正文，Libre Bodoni/系统衬线用于标题；中文使用平台系统字体回退。
- **图形语言：** 轻量线框、内容索引、编辑器式代码卡片和项目几何图形；图标统一为 24 网格、4–20 内容区、1.7 圆头描边，导航图标与状态标记共用同一套几何。项目封面在暗色主题下切换为深色底与浅色标记。
- **动效：** 仅用于悬停反馈和轻微进入效果；遵循 `prefers-reduced-motion`。

### 标志与字标

标志由几何 **C** 与一枚粉色句点组成：C 取 "Code"，句点收束成 "Liter" 的落款，像杂志版权页上的署名标记。字标把名字拆成两种语言——`Code` 用 Space Grotesk，`Liter` 用 Libre Bodoni——让代码与文学在同一行并置。

- **网格：** 32×32，3px 圆头笔画，句点 4×4；最小使用尺寸 16px。
- **颜色：** C 使用 `currentColor`，句点使用 `--header-accent`（浅色 `#EC4899` / 深色 `#F28BBB`）。
- **资产：** [`public/favicon.svg`](../public/favicon.svg)（深底浅标）、[`logo/codeliter-mark.svg`](./logo/codeliter-mark.svg)（透明底，可改色）。
- **方案对照：** 打开 [`logo/concepts.html`](./logo/concepts.html) 查看六个探索方向与字标组合。

### 列表与详情

笔记列表在页首说明内容范围，工具栏提供分类与关键词筛选，结果保留总数、清除筛选入口和分页；无结果时给出恢复建议。详情页以标题和摘要建立阅读上下文，桌面端使用章节目录辅助定位，移动端将目录放在正文之前。

## 关键交互与状态

- 顶部搜索按钮、`/` 与 `⌘/Ctrl + K` 打开快速搜索；`Esc` 关闭，焦点进入对话框并在对话框内循环。
- 分类与搜索组合过滤；列表分页随筛选条件变化重置。
- 列表项和项目卡片进入稳定 slug URL；浏览器前进/后退可恢复页面路由。
- 空结果保留查询条件并提供清除筛选操作。
- 移动端导航折叠为可展开菜单，分类栏可横向滚动，卡片与长文改为单列。
- 顶部提供语言切换和主题选择；主题偏好保存于本地，系统模式会响应操作系统外观变化。

## 内容与技术边界

页面使用本地示例数据演示内容模块和项目模块。正式接入时，对齐技术方案中的 `Note`、`Project`、`Category`、`Tag` 字段；公开查询仅返回已发布内容。认证、后台写操作、论坛、上传与生产 SEO 元信息不属于当前前端演示范围。
